# 自定义知识库覆盖（按文件回落内置）

## Goal

允许用户用自己的知识库目录**按文件覆盖**内置 `knowledge/`：自定义目录存在同名文件（相对路径同构）则使用，不存在则回落内置版。改一个文件零拷贝成本，CLI 升级后新增内置文件自动生效。发布为 `duanju-cli@0.2.0`。

## Requirements

### 功能需求

1. **按文件覆盖 + 回落内置**：加载每个知识文件时，先查自定义根目录下的同构相对路径（如 `title/references/keyword-bank.md`），存在则用自定义版，否则用内置版。不做整树替换、不做追加注入。
2. **三级配置入口**（沿用现有优先级链，高→低）：
   - CLI 参数 `--knowledge <path>`：注册到 package / title / write / revise / run 五个调模型的命令；相对路径相对当前工作目录
   - 项目 `duanju.json` 的 `knowledgePath` 字段：相对路径相对项目目录
   - 全局 `~/.duanju/config.json` 的 `knowledgePath` 字段：**必须为绝对路径**，否则报错
3. **前置校验**：解析出的自定义根目录不存在 → CliError 中文报错（含解析后的完整路径与配置来源）。
4. **透明提示**：生成前若命中自定义文件，打印一行清单：`使用自定义知识文件：<相对路径>（共 N 个）`。
5. **边界行为**：自定义文件为空 → 警告但照用；自定义目录中的多余文件（内置不认识的）→ 忽略。
6. **config 向导**：`duanju config` 追加可选"自定义知识库路径"一步（可留空跳过；填了做绝对路径与存在性校验）。
7. **向后兼容**：未配置任何 knowledgePath 时行为与 v0.1.1 完全一致。

### 非功能需求

- 无隐藏全局状态：customRoot 由配置链解析后显式传参（方案 A，用户在三方案对比后选定）
- README 补"自定义知识库"章节（目录同构说明、三级配置示例、覆盖提示说明）
- 版本 bump `0.2.0`

### 明确不做

- 整树替换模式、追加注入模式
- 自定义文件内容结构校验（用户自担生成质量风险，README 说明）
- 多知识库叠加（仅单一 customRoot）

## Acceptance Criteria

- [ ] 回落矩阵单测：自定义有/无同名文件、空文件警告、多余文件忽略
- [ ] 三级优先级单测：CLI > 项目 > 全局；相对路径基准正确（cwd / 项目目录）；全局相对路径报错
- [ ] 目录不存在的 CliError 报错含完整路径与配置来源
- [ ] mock 集成：prompt 中注入的确为自定义文件内容；命中清单提示输出正确
- [ ] 回归：未配置 knowledgePath 时全量既有测试（156+）行为不变
- [ ] `duanju config` 向导含可选知识库路径步骤

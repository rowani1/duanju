# 女主人设模板

## 隐忍清醒型

- 表面忍，内里一直在记账
- 适合：追妻火葬场、离婚逆袭、婚姻反击
- 爽点：一旦抽离就不回头

## 外柔内硬型

- 外表看似柔弱，关键时刻不退
- 适合：替嫁、冲喜、带娃回归
- 爽点：反差感强

## 冷静狠决型

- 不多话，行动快，善于断关系
- 适合：全家后悔、和离后反杀、重生翻盘
- 爽点：决绝、利落

## 柔弱外壳强心型

- 适合做开篇被轻视、后续翻盘
- 适合：真假千金、乡下回归、替嫁

# 男主人设模板

## 冷硬掌权型

- 权势高
- 话少
- 前期误伤，后期沦陷
- 适合：总裁、王爷、权臣

## 禁欲深情型

- 表面克制，实际早有感情
- 适合：先婚后爱、蓄谋已久线

## 占有欲失控型

- 女主离开后破防
- 适合：追妻火葬场、带娃回归

## 病弱阴鸷型

- 身体弱，权力未必弱
- 适合：冲喜、医妃

# 反派模板

## 恶婆婆

- 代表婚姻制度压迫
- 功能：给女主现实委屈

## 继妹/嫡姐/妹妹

- 代表资源剥夺与身份羞辱
- 功能：提供女性对手盘

## 白月光幻影

- 可是真人，也可只是误会
- 功能：制造情感误判

## 偏心父母

- 功能：强化现实情感代入

## 高位妃嫔/后宅长辈

- 功能：提供规则型压迫

# 角色卡固定字段

每次输出人设包时，至少写清：

- 身份
- 表面性格
- 真实驱动
- 最怕失去什么
- 最能刺痛对方的话/事
- 对这段关系的初始态度

# 人设禁忌

- 不要把女主写成只会挨打的受气包
- 不要把男主写成纯工具型提款机
- 不要让反派只会骂人，不会做实事
- 不要让每个人都"疯"，会失真

# 正面示例与反面示例

## 女主人设示例

### 隐忍清醒型 — 正面

- 参考标杆：《盛夏芬德拉》类清醒女主
- 表现方式：她不是不痛，而是痛了也不哭。她不是不在乎，而是在乎的同时一直在想怎么脱身。每次被羞辱后，她做的第一件事不是哭，而是打开手机录音、拍照存证，然后回房间在笔记本上记下"第三次"
- 爽点来源：当她终于翻出那本"账本"时，所有人都慌了

### 隐忍清醒型 — 反面

- 翻车写法：女主被婆婆打了 15 章，每章都是"她默默流泪，心想再忍一次"。直到第 16 章突然变成武林高手把全家打翻
- 问题诊断：忍了太久等于纯受气包，突然爆发没有铺垫等于角色崩坏
- 修复方法：每章的"忍"必须伴随一个"暗中准备"的动作

### 外柔内硬型 — 正面

- 参考标杆：《好一个乖乖女》伪乖乖女设定
- 表现方式：她笑着答应所有人的要求，但每一个答应都带条件。她帮你做，但她记得你欠她的。柔软只是表面策略，内核是"我不会白受委屈"
- 爽点来源：所有人觉得她好欺负，直到她拿出签好的协议

### 外柔内硬型 — 反面

- 翻车写法：所谓"外柔"变成真的全程柔弱，"内硬"只体现在旁白说"她内心其实很坚强"。行动上毫无反击
- 问题诊断：语言告诉读者"她很强"不如行动展示"她很强"
- 修复方法：在前 3 章内至少安排一次具体的小反击行动

## 男主人设示例

### 冷硬掌权型 — 正面

- 表现方式：他不解释，只做。他不说"我保护你"，但他在她不知道的时候挡掉了三次暗箭。他的"冷"不是冷漠，是"我还没想好怎么面对你"
- 爽点来源：他破防的瞬间——"你是不是以为我不在乎？"一句话，声音都在抖

### 冷硬掌权型 — 反面

- 翻车写法：男主全程嘴毒心黑，骂女主"你配吗？"连骂 10 章。到了第 11 章突然甜蜜告白
- 问题诊断：伤害过重且无代价，读者已经恨他了。突然转甜等于强行洗白
- 修复方法：伤害每升级一次，男主必须有一次"暗中后悔"的行为铺垫

# 人设弧线模板

## 三阶段弧线（推荐）

### 阶段一：入局（第 1-5 章）

- 女主：被压迫/被轻视/被逼入局 → 展示她"和别人不一样"的第一个信号
- 男主：高位审视/冷淡/误判 → 展示他"不像表面那么简单"的第一个裂缝
- 反派：施压/占上风 → 展示她的威胁不只是嘴炮

### 阶段二：觉醒（第 6-12 章）

- 女主：第一次正面反击 → 站住脚 → 获得第一个盟友/资源
- 男主：开始动摇 → 第一次出手相护（嘴上不承认）→ 破防
- 反派：升级手段 → 但第一次被女主挡住

### 阶段三：翻盘（第 13-20 章）

- 女主：掌握关键真相/资源 → 公开翻盘 → 重新定义关系
- 男主：完全失控/站队 → 旧账清算 → 关系重组
- 反派：最后一搏 → 彻底败落

# 人设组合禁区

以下组合容易翻车，使用时需特别注意：

| 组合 | 翻车风险 | 处理建议 |
|------|---------|---------|
| 冷静狠决女主 + 占有欲失控男主 | 两个都太"硬"，缺少化学反应。读者找不到代入点 | 至少一方必须有"柔"的裂缝——女主对孩子、男主对旧伤 |
| 柔弱外壳女主 + 禁欲深情男主 | 双方都太"闷"，缺少表面冲突。纯内心戏会变散文 | 必须有一个外部压力源持续制造对峙场景 |
| 冷硬掌权男主 + 冷硬掌权反派 | 两个"冷硬"撞脸，读者分不清 | 一个必须转化为"假冷硬"——表面冷但驱动力不同 |
| 全员疯批配置 | 所有角色都极端 → 情绪失真 → 读者审美疲劳 | 至少留一个"正常人"作为读者视角锚点 |

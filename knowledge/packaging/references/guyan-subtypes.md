# 古言类子类库

## 冲喜

- 设定底盘：病弱王爷/将军/世子命悬一线，女主被送去冲喜
- 女主能力模块：医术、空间物资、清醒胆气、打脸能力
- 男主权力模块：病弱但高位、传闻阴鸷、醒来后护短
- 对手盘：王府侧妃、恶婆婆、旧部、府中下人、外部政敌
- 高频场景：
  - 喜床苏醒
  - 王爷吐血/中毒
  - 女主救人立威
- 标题关键词：冲喜、王爷、王妃、福宝、医妃
- 雷区：
  - 病弱设定只挂名
  - 女主全靠外挂无脑碾压

## 替嫁

- 设定底盘：嫡女或庶女因家族安排代替他人出嫁
- 女主能力模块：隐忍反击、宅斗心性、医术/重生记忆/身份秘密
- 男主权力模块：王爷、侯府世子、权臣
- 对手盘：继母、嫡姐、原定新娘、婆家内宅
- 高频场景：
  - 出嫁前被羞辱
  - 洞房对峙
  - 婚后首次立规矩
- 标题关键词：替嫁、和离、王妃、世子、嫡女
- 雷区：
  - 替嫁动机过空
  - 婚后立刻甜宠没压力

## 医妃

- 设定底盘：女主带医术进入高门婚姻或宫廷
- 女主能力模块：救命、解毒、验伤、空间药材
- 男主权力模块：病王爷、权臣、冷面帝王
- 对手盘：太医、后宅敌人、后宫妃嫔、外部政敌
- 高频场景：
  - 当众救人
  - 验毒翻案
  - 男主因女主破例
- 标题关键词：医妃、神医、王爷、王妃、解毒
- 雷区：
  - 医术写成万能外挂
  - 缺少情感压力

## 宫斗

- 设定底盘：低位妃嫔入宫求生，逐步上位
- 女主能力模块：生子、谋略、自保、收买人心
- 男主权力模块：皇帝，感情不可全信
- 对手盘：高位妃嫔、皇后、宫女太监系统、后宫规则
- 高频场景：
  - 初次侍寝
  - 怀孕保胎
  - 借刀杀人
- 标题关键词：宫斗、侍寝、贵妃、生子、上位
- 雷区：
  - 单纯宫规介绍过多
  - 派系太杂导致切片性差

## 宅斗

- 设定底盘：高门内宅中嫡庶、婆媳、姐妹、子嗣争斗
- 女主能力模块：识人、反制、掌家、拿证据
- 男主权力模块：相对弱化，只做关键站队
- 对手盘：继母、嫡姐、婆婆、妾室
- 高频场景：
  - 家宴发难
  - 嫁妆之争
  - 管家权转移
- 标题关键词：宅斗、嫡女、掌家、侯府
- 雷区：
  - 冲突太琐碎
  - 没有核心关系拉扯

## 重生翻盘

- 设定底盘：女主前世惨死，今生带记忆改命
- 女主能力模块：先知、复盘、布局、避坑
- 男主权力模块：前世错过的人、前夫对照组、新盟友
- 对手盘：前世仇人、亲族、旧情人、恶毒姐妹
- 高频场景：
  - 睁眼回到关键节点
  - 拒婚/改嫁
  - 抢先一步布局
- 标题关键词：重生、改命、和离、复仇、翻盘
- 雷区：
  - 重生优势不用
  - 只说后悔不做反击

## 和离后反杀

- 设定底盘：女主婚内受辱，和离后价值回升，前夫后悔
- 女主能力模块：清醒、事业或医术、身份秘密、再婚高配
- 男主权力模块：前夫对照组 + 新高位男主
- 对手盘：前夫家、外室、婆家、朝廷流言
- 高频场景：
  - 和离书
  - 女主离府
  - 高位人物当众护她
- 标题关键词：和离后、前夫、高攀不起、王爷后悔
- 雷区：
  - 和离后剧情发散
  - 新男主入场太晚

## 鬼妻 / 亡妻虐恋（2026 S 级新晋）

- 设定底盘：女主已死（或假死 / 灵魂状态 / 重生归来），男主在亡妻"在场"的视角下完成赎罪
- 女主能力模块：旁观回忆、灵魂干预、记忆碎片、可控可见 / 不可见
- 男主权力模块：高位但崩塌型、表面伪君子型、深藏悔恨型
- 对手盘：男主身边的新欢 / 假亡妻替身、家族施压者、过往真相隐藏者
- 高频场景：
  - 男主在亡妻牌位前痛哭 / 自语
  - 鬼妻看见男主对她的"赎罪式深情"
  - 旧物 / 旧地点触发记忆闪回
  - 真相揭穿：他从未变心 / 他正在替她复仇
- 标题关键词：夫人死的、亡妻、鬼妻、第三年、回不去、白月光
- 标杆案例：《夫人死的第三年》（红果 6850 万 4 榜冠军）
- 雷区：
  - 鬼妻只能看不能动，戏份过弱
  - 男主只哭不行动，没有具体赎罪事件
  - 真相揭得太早 / 太晚

## 女将军 / 强强古装（2026 S 级新晋）

- 设定底盘：女主以将军 / 武将 / 战场身份立足，与同等位阶男主"强强对峙"再走向爱情
- 女主能力模块：兵权、武力、战场策略、家族军事力量
- 男主权力模块：将门世子 / 帝王 / 同级将领 / 敌国主帅
- 对手盘：朝堂猜忌、同级将领、政治联姻派、敌国对手
- 高频场景：
  - 战场 / 演武场公开较量
  - 朝堂封赏对峙
  - 联姻棋局上的战略合作
  - 男主"捉婿"式追妻
- 标题关键词：女将军、专治不服、将门、捉婿、不服、夫人、镇守
- 标杆案例：《夫人她专治不服 3 之将门捉婿》（12567 万累计破 10 亿）
- 雷区：
  - 女主只是挂将军名，不上战场不出兵
  - 强强变成强弱，男主立刻让位
  - 战争场面过实，触发短剧预算与场景禁区

## 留后娘子（冲喜变体，2026 A 级新晋）

- 设定底盘：寡妇 / 罪女为救亲人 / 自保被迫成为"留后娘子"，与狱中或落难男主结下因果
- 女主能力模块：烟火气生存、医术 / 厨艺 / 手艺、低位坚韧
- 男主权力模块：诬陷入狱型、落难世子型、被夺权型
- 对手盘：男主仇家、衙门、村中长舌、想分她财产的亲戚
- 高频场景：
  - 探监送饭
  - 一碗馄饨 / 一把伞 / 一支簪子的温暖细节
  - 男主翻案 / 复出
  - 双向救赎对峙
- 标题关键词：留后、二嫁、上上签、寡妇、狱中、馄饨
- 标杆案例：《二嫁上上签》（改编自《留后娘子》，红果 6289 万）
- 雷区：
  - 重口宅斗化，丢失烟火气底色
  - 男主复出后立刻强势压女主
  - 没有具体物件 / 细节支撑双向救赎

## 古言甜宠 + 失忆轮回（2026 A 级新晋）

- 设定底盘：男女主曾相爱但因一方失忆 / 死亡 / 时空错位被分开，男主在轮回 / 等待中守候
- 女主能力模块：记忆觉醒、灵性 / 仙缘、再爱一次的勇气
- 男主权力模块：帝王 / 神祇 / 摄政王、长情守护型、单方面坚守型
- 对手盘：命运 / 天道 / 时间、阻挠两人的旧势力、记忆抹除者
- 高频场景：
  - 雨夜守候
  - 女主初遇又像旧识
  - 触发碎片记忆的具体物件
  - 第一次说出"我等你很久了"
- 标题关键词：此生、重逢、轮回、忘川、若得、相思
- 标杆案例：《此生若得萧俞白》（红果 6325 万、话题破 3 亿）
- 雷区：
  - 失忆 / 轮回设定只用一次，后续靠纯甜
  - 男主守候过虚，没有具体守候动作
  - 命运对手盘虚化为口头禅

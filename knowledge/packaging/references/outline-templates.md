# 10章短纲模板

## 通用节奏

- 第1章：核心冲突抛出
- 第2章：女主处境加压
- 第3章：第一次反击或第一次救人
- 第4章：男主开始注意她
- 第5章：旧敌/家人再施压
- 第6章：第二次反击，局势翻转
- 第7章：情感误判或秘密揭露
- 第8章：男主站队或失控
- 第9章：更大真相揭开
- 第10章：关系进入新阶段

# 20章短纲模板

## 总裁线

- 1-3章：入局、羞辱、绑定
- 4-6章：女主第一次立起来
- 7-10章：男主动摇，旧敌发难
- 11-14章：身份或真相翻转
- 15-17章：情感破防，男主失控
- 18-20章：关系重组，进入下一阶段

## 古言线

- 1-3章：婚配/入府/入宫
- 4-6章：立威/救命/避害
- 7-10章：后宅或后宫第一轮对杀
- 11-14章：女主势力初成
- 15-17章：真相、旧仇、身份翻转
- 18-20章：男主站队，女主升位

## 现实情感线

- 1-3章：压迫与羞辱
- 4-6章：觉醒与第一次反击
- 7-10章：旧家庭/前夫持续施压
- 11-14章：女主掌握证据或资源
- 15-17章：公开撕破脸
- 18-20章：全家后悔或前夫求和

# 每章固定字段

每章都尽量写清：

- 核心事件
- 情绪点
- 反转点
- 结尾钩子

# 钩子类型库

- 有人听见了不该听见的话
- 有人突然出现护女主
- 真相被揭一半
- 文件/和离书/离婚书/诊断书出现
- 孩子一句话让场面失控
- 王爷/总裁/前夫破例

# 章纲禁忌

- 不要连续三章只吵架不推进
- 不要连续三章只甜不压
- 不要让反转和主线无关
- 不要写成流水账

# 30 章完整长纲模板

## 第一幕：入局与压迫（1-8 章）

| 章节 | 功能 | 情绪曲线 |
|------|------|---------|
| 1 | 核心冲突抛出，开篇钩子 | ⬇️ 压（羞辱/绝境） |
| 2 | 女主处境加压，关系绑定 | ⬇️ 压（更具体的损失） |
| 3 | 第一次小反击或展示能力 | ⬆️ 顶（第一个爽点） |
| 4 | 男主注意到她/外界新压力 | ➡️ 平（节奏呼吸） |
| 5 | 旧敌/家人再施压 | ⬇️ 压（升级） |
| 6 | 第二次反击，局势翻转 | ⬆️ 翻（中反转） |
| 7 | 男主第一次站队或暗中相护 | ⬆️ 甜（有克制的心动） |
| 8 | 反派升级手段 | ⬇️ 压（更大威胁） |

## 第二幕：觉醒与对峙（9-18 章）

| 章节 | 功能 | 情绪曲线 |

| 30 | 全文收束钩子（可以留番外伏笔） | 🔀 吊 |

# 情绪曲线标注说明

| 符号 | 含义 | 使用频率限制 |
|------|------|-------------|
| ⬇️ 压 | 给主角具体压力 | 不能连续超过 3 章 |
| ⬆️ 顶 | 主角回应/反击 | 必须紧跟在"压"之后 |
| ⬆️ 翻 | 局势反转 | 每 5-8 章至少 1 次 |
| ⬆️ 甜 | 情感升温 | 不能连续超过 2 章 |
| ➡️ 平 | 节奏呼吸/信息释放 | 不能连续超过 1 章 |
| 🔀 转 | 信息反转/真相揭露 | 每 4-6 章至少 1 次 |
| 🔀 吊 | 留下驱动力和悬念 | 每章结尾必须有 |

# 钩子轮换规则

## 不允许连续 3 章使用同类型钩子

### 钩子类型库（按类型编号）

| 类型 | 具体钩子 |
|------|---------|
| A-人物登场 | 有人突然来了/有人出现护女主 |
| B-真相揭露 | 真相被揭一半/证据出现 |
| C-文件道具 | 和离书/离婚协议/诊断书/遗嘱 |
| D-孩子引爆 | 孩子一句话让场面失控/孩子喊错了人 |
| E-角色异常 | 王爷/总裁/前夫破例/失控 |
| F-选择悬念 | 女主决定离开/签还是不签 |
| G-偷听偷看 | 她看见了不该看见的/有人听见了 |

### 轮换规则

- 相邻 3 章内不得使用同一类型钩子
- 每 5 章至少覆盖 3 种以上不同类型
- 大反转章节（第 6、13、17、25 章）推荐使用 B 或 E 型
- 过渡章节推荐使用 F 或 G 型

# 总裁类子类库

## 追妻火葬场

- 一句话定义：男主前期冷硬伤透女主，离开后发现自己离不开她
- 女主人设模板：隐忍清醒型、失望抽离型、离开后价值回归型
- 男主人设模板：高位冷硬型、嘴硬后悔型、占有欲极强型
- 常见开篇：
  - 离婚现场
  - 复婚被拒
  - 女主被羞辱后转身离开
- 常见反转：
  - 男主早就知道真相却没说
  - 女主身份反转
  - 男主开始低位求和
- 标题关键词：离婚后、前夫、后悔、疯了、追妻、火葬场
- 雷区：
  - 男主伤害过重却无代价
  - 女主反复心软没有成长

- 雷区：

  - 婚后只有甜没有压

## 少夫人地域变体（2026 S 级新晋）

- 一句话定义：女主以"少夫人"身份回到具有强地域辨识度的环境，借地域文化代入感放大身份反差与情感冲击
- 女主人设模板：低调归来型、地域归属型、外表柔内核硬型
- 男主人设模板：地域大院掌权型、深沉护妻型、有地域口音习惯的霸总
- 对手盘：地域势力、本地豪门旧友、地方派系、家族长辈
- 常见开篇：
  - 女主穿东北棉袄归家、踏入老式大院
  - 飞机刚落地遇见男主
  - 在地方饭桌上被刁难
- 常见反转：
  - 女主才是地方真正的资源持有者
  - 男主一直在用地域势力护她
  - 当地人才是她真正的靠山
- 标题关键词：少夫人、东北、北方、回家、归来、xx 女王、大院
- 标杆案例：《少夫人在东北》（2026 Q1 红果破 30 亿，第一）
- 雷区：
  - 地域只是地名贴牌，没有方言 / 习俗 / 饮食 / 服饰落地
  - 把地域写成猎奇看点而非情感共振
  - 失去都市豪门感，沦为乡土剧

## 双向治愈型总裁（2026 S 级新晋）

- 一句话定义：弱化单霸总爽点，转向"高能量女主 × 创伤型总裁"的相互治愈
- 女主人设模板：话痨高能量型、阳光直球型、不怕冷暴力型、主动破防型
- 男主人设模板：缄默症 / 选择性失语型、社恐高位型、童年创伤型、需要被叫名字才有反应型
- 对手盘：男主家族中阻碍治愈的人、女主旧情感包袱、外部医学权威、男主自我封闭
- 常见开篇：
  - 女主第一次闯进男主无声的世界
  - 误打误撞当陪护
  - 当众替男主接话
- 常见反转：
  - 男主其实记得每一次她说的话
  - 男主写下了厚厚一本"她说过的话"
  - 治愈不是单向的，女主也有伤
- 标题关键词：念念有词、爱我请大声说、不语、话痨、阳光、解语
- 标杆案例：《念念有词》（话痨女 × 缄默症总裁）
- 雷区：
  - 把缄默症 / 创伤设定写成纯卖惨外挂
  - 女主成为唠叨工具人，缺少自己的痛
  - 治愈太顺利，没有过程

## 疯批囚禁 + 高岭之花跌落（2026 A 级新晋）

- 一句话定义：女主放弃后，原本高高在上的男主"发疯"——囚禁 / 偏执 / 极端追求
- 女主人设模板：清醒抽离型、放弃前夫 / 旧爱型、低头不再求型
- 男主人设模板：跌落神坛型、疯批偏执型、占有欲爆表型、自毁式追妻型
- 对手盘：女主新生活的支持系统（朋友 / 工作 / 新男人）、男主内心理智线
- 常见开篇：
  - 女主搬家逃离
  - 男主在新住处出现
  - 女主拒绝再见
- 常见反转：
  - 男主早就为她跌落多年
  - 她以为他冷漠其实他病态保护
  - 疯批表象下藏着真相（被陷害）
- 标题关键词：他疯了、囚禁、跌落神坛、神坛、高岭之花、偏执
- 雷区：
  - 疯批写成无脑施暴，违背女频"先虐后爽 + 男主低位"的爽感逻辑
  - 囚禁场景过实导致违反平台合规
  - 男主始终高位无代价，让女主像受害者而非掌控者

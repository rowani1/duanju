# 四大主类总览

## 总裁

- 目标情绪：婚恋羞辱、身份反杀、先虐后爽、男主后悔、强占有欲、双向治愈、地域反差
- 典型关键词：离婚、复婚、追妻、先婚后爱、替嫁、带娃回国、白月光、假千金、豪门弃妇、少夫人、疯批、缄默症
- 适合短剧化的原因：
  - 关系清晰
  - 场景集中
  - 高情绪对白多
  - 低成本可拍
- 不适合写什么：
  - 纯甜宠无压迫
  - 豪门设定过大但关系弱
  - 职场商战大篇幅专业线
- 2026 风向补充：
  - 地域变体崛起（《少夫人在东北》破 30 亿，2026 Q1 第一）
  - 双向治愈型从单霸总爽点向情绪流动转型（《念念有词》话痨女 × 缄默症总裁）
  - 疯批囚禁 + 高岭之花跌落成新晋虐恋变体

## 古言

- 目标情绪：命运翻盘、身份逆转、婚姻入局、后宅压迫、宫廷上位、亡妻执念、强强对峙
- 典型关键词：冲喜、替嫁、王爷、医妃、宫斗、宅斗、重生、和离、嫡庶、王府、留后娘子、女将军、鬼妻、亡妻、失忆轮回
- 适合短剧化的原因：
  - 强身份差
  - 礼制压迫天然带戏
  - 冲突高度集中在婚姻和家族
  - 爽点可快速兑现
- 不适合写什么：
  - 大权谋朝堂群像
  - 大战争线
  - 复杂世界观设定
- 2026 风向补充：
  - 鬼妻 / 亡妻虐恋成新晋热门（《夫人死的第三年》6850 万 4 榜冠军）
  - 女将军 / 强强古装爆发（《夫人她专治不服 3》12567 万累计破 10 亿）
  - 留后娘子 / 冲喜变体（《二嫁上上签》6289 万）
  - 古言甜宠 + 失忆轮回（《此生若得萧俞白》话题破 3 亿）

## 女频现实情感

- 目标情绪：婚姻窒息、原生家庭压迫、全家后悔、女性觉醒、现实反击、自我成长（剥离感情依附）
- 典型关键词：离婚、婆家、偏心父母、姐姐妹妹、断亲、逆袭、全家后悔、亲情背刺、无 CP、流产流、绝育、误诊
- 适合短剧化的原因：
  - 情绪代入强
  - 现实议题明显
  - 冲突近身
  - 场景改编成本低
- 不适合写什么：
  - 纯鸡汤成长
  - 空喊大女主
  - 缺少具体恶人和具体羞辱
- 2026 风向补充：
  - 无 CP 大女主成长成为 2025 网文十大关键词首位（番茄无 CP 分类首位关联词即"无 CP 大女主"）
  - 流产流（虐恋伪装、绝育、误诊变体）成为女频爆款新密码 TOP2
  - 整体从"狗血爽文"向"折射现实焦虑 + 女性自我表达"过渡

## 年代/穿越

- 目标情绪：生存逆袭、穿越金手指爽感、年代怀旧、家庭分家对抗、从穷到富的翻身、地域文化代入
- 典型关键词：穿越、重生、六零、七零、八零、九零、空间、种田、分家、知青、军婚、下乡、高考、万元户、下岗、东北、南宁
- 适合短剧化的原因：
  - 年代滤镜天然有辨识度和怀旧共鸣
  - 生存压力具体可感（粮食、票证、住房、下岗）
  - 金手指+年代规则构成天然冲突
  - AI漫剧友好——年代服化道有成熟素材
  - 切片性强，每个生存难题可独立成集
- 不适合写什么：
  - 穿越只是皮，剧情完全现代化
  - 金手指无限制碾压，无真实压力
  - 只有时代设定没有人物关系冲突
  - 年代背景考据过重，影响节奏
- 2026 风向补充：
  - 90 年代下岗潮成为新增热门切口（红果东北剧场《东北 90 之沈阳女王》：90 年代国企改革 + 下岗女工创业）
  - 地域文化变体崛起（南宁《大小姐的平常心》上线两日番茄热度 2439 万 + 红果 1363 万）
  - 红果重点扶持东北 / 南宁 / 川渝 / 西北等具有强地域辨识度的题材

# 分类判断规则

## 优先级矩阵

- `S级主推`
  - 总裁：追妻火葬场、先婚后爱、离婚逆袭、替嫁错嫁、真假千金、带娃回归、**少夫人地域变体**、**双向治愈型总裁**
  - 古言：冲喜、替嫁、医妃、宫斗、重生翻盘、和离后反杀、**鬼妻 / 亡妻虐恋**、**女将军 / 强强古装**
  - 现实情感：婚姻反击、全家后悔、原生家庭反杀、**无 CP 大女主成长**、**流产流**
  - 年代/穿越：穿越种田、年代重生、军婚甜宠、**90 年代下岗逆袭**、**地域文化变体**
- `A级可用`
  - 总裁：白月光误会线、契约婚姻、疯批囚禁 + 高岭之花跌落
  - 古言：宅斗、病娇权臣婚后线、留后娘子（冲喜变体）、古言甜宠 + 失忆轮回
  - 现实情感：姐妹撕裂、职场婚恋双压迫
  - 年代/穿越：系统空间、穿书改命、知青下乡
- `B级弱支持`
  - 娱乐圈女频
  - 轻穿书轻喜
  - 纯甜宠

## 快速判断法

- 如果冲突核心是”婚恋关系 + 豪门权势 + 身份羞辱”，归 `总裁`
- 如果冲突核心是”婚配入局 + 后宅/宫廷/王府规则 + 身份翻盘”，归 `古言`
- 如果冲突核心是”现实婚姻/家庭压迫 + 女性反击”，归 `女频现实情感`
- 如果冲突核心是”年代生存压力 + 穿越/重生金手指 + 时代规则”，归 `年代/穿越`

## 边界判断

- `真假千金 + 豪门婚恋` 优先归 `总裁`
- `重生王妃 + 医术空间` 归 `古言`
- `穿越到六七八十年代 + 空间/系统 + 农村/部队` 归 `年代/穿越`
- `重生到年代 + 分家/高考/做生意` 归 `年代/穿越`
- `军婚 + 部队大院 + 年代背景` 归 `年代/穿越`
- `离婚后前夫后悔 + 婆家吸血` 看冲突主轴：
  - 以前夫为主，归 `总裁`
  - 以家庭压迫为主，归 `女频现实情感`
- `穿越但核心是王府/宫廷规则` 归 `古言`
- `穿越但核心是现代豪门+身份` 归 `总裁`
- `90 年代下岗 + 国企改革 + 创业` 归 `年代/穿越`（90 年代切口）
- `地域文化（东北/南宁/川渝）+ 现代家庭` 看冲突主轴：
  - 以创业 / 时代变迁为主，归 `年代/穿越`
  - 以家庭压迫 / 觉醒为主，归 `女频现实情感`
- `亡妻执念 + 男主赎罪 + 古代背景` 归 `古言`（鬼妻虐恋线）
- `女主无 CP + 自我成长 + 现代` 归 `女频现实情感`（无 CP 大女主线）

## 短剧适配评分

满足以下 5 项越多，越适合继续包装：

- 开篇 500 字内能抛出核心冲突
- 主角关系一句话能说清
- 主要场景在 3-5 个核心空间内可成立
- 每章都能做切片
- 爽点依赖关系，而不是依赖大设定

## 2026 平台合规层（强制检查）

> 自 2026.01.01 起红果实施微短剧三档分类，包装阶段必须前置评估。

| 投资档位 | 标准 | 题材限制 |
|---------|------|---------|
| **重点微短剧** | 投资 ≥ 300 万元 | 涉及政治、军事、外交、国家安全等特殊题材必须按重点剧申报 |
| **普通微短剧** | 投资 100-300 万元 | 一般题材 |
| **其他微短剧** | 投资 < 100 万元 | 一般题材 |

包装时必须提示：

- 题材若触碰政治 / 军事 / 外交 / 国安议题（含部分军婚、年代政治背景），需走重点剧申报通道
- 涉及历史人物、革命题材、民族议题需提前评估合规性
- 系列化 IP（红果主流方向）需在初版章纲中预留 2-3 季延展空间

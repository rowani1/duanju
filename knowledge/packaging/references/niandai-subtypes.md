# 年代/穿越类子类库

## 穿越种田

- 一句话定义：女主穿越到贫苦年代，靠现代知识/金手指在农村生存致富
- 女主人设模板：现代灵魂实干型、生存能力强型、带空间/系统型
- 男主人设模板：村里糙汉护短型、退伍军人型、寡言能干型
- 对手盘：极品婆家、好吃懒做亲戚、村霸、生产队长
- 高频场景：
  - 醒来在破屋/牛棚
  - 赶集卖货
  - 家庭分家
  - 大队开会
- 标题关键词：穿越、种田、空间、六零、七零、致富、分家
- 雷区：
  - 金手指太强失去生存压力
  - 年代背景只是皮，剧情和现代没区别
  - 全员工具人为女主服务

## 系统空间

- 一句话定义：女主获得系统或随身空间，在年代环境中逐步改善生活、碾压对手
- 女主人设模板：低调闷声发财型、外柔内精明型、知识储备型
- 男主人设模板：军官/干部型、沉默深情型、家庭顶梁柱型
- 对手盘：吸血亲戚、举报邻居、嫉妒同事、严格审查
- 高频场景：
  - 空间偷偷取物
  - 被人盯上/怀疑
  - 用物资换人情
  - 关键时刻救命
- 标题关键词：空间、系统、随身、物资、年代、囤货
- 雷区：
  - 空间万能，缺乏真实压力
  - 年代规则形同虚设

## 年代重生

- 一句话定义：女主重生回六七八十年代，带着前世记忆避坑改命
- 女主人设模板：前世吃亏型、重来后果断型、利用记忆布局型
- 男主人设模板：前世错过型、这一世被抢先绑定型、潜力股型
- 对手盘：前世害她的人、抢她姻缘的闺蜜/亲戚、旧时代规则
- 高频场景：
  - 重生醒来在老家
  - 抢先一步拒婚/改嫁
  - 高考/招工/参军关键节点
  - 前世仇人的阴谋被提前拆穿
- 标题关键词：重生、六零、七零、八零、改命、高考、翻盘
- 雷区：
  - 重生记忆不用，只靠金手指
  - 蝴蝶效应完全不考虑

## 穿书改命

- 一句话定义：女主穿进年代文/苦情文，知道剧情走向，主动避开悲惨结局
- 女主人设模板：知道剧情型、拒绝当炮灰型、反向操作型
- 男主人设模板：书中反派型、原本该错过的人、被女主改变命运型
- 对手盘：原书女主、原书男主、命运惯性、剧情纠正力
- 高频场景：
  - 发现自己穿进书里
  - 拒绝和原男主绑定
  - 抢先抱大腿/站队
  - 剧情偏离后的连锁反应
- 标题关键词：穿书、炮灰、改命、年代文、反派、女配
- 雷区：
  - 穿书设定只在第一章提，后面忘了
  - 和普通重生没区别

## 军婚甜宠

- 一句话定义：女主嫁给军人/干部，在部队大院或驻地展开婚后生活
- 女主人设模板：城里下乡型、随军贤内助型、有手艺/医术型
- 男主人设模板：铁血军官型、嘴笨心热型、升职线清晰型
- 对手盘：军嫂间的明争暗斗、婆家偏心、举报/造谣、政策变动
- 高频场景：
  - 相亲/领证
  - 随军搬家
  - 军嫂互撕
  - 男主执行任务不在家
- 标题关键词：军婚、军嫂、首长、部队、随军、大院
- 雷区：
  - 军旅只是背景板
  - 婚后纯甜无压力

## 知青下乡

- 一句话定义：女主以知青身份下乡，在农村生存、建设、恋爱
- 女主人设模板：城里娇小姐蜕变型、带技能的务实型、被迫下乡的觉醒型
- 男主人设模板：大队长/村干部型、知青同伴型、退伍回乡型
- 对手盘：恶毒室友、想拉她下水的坏知青、抢回城名额的人
- 高频场景：
  - 坐绿皮火车下乡
  - 分配住房/干农活
  - 推荐上大学/回城名额竞争
  - 举报与反举报
- 标题关键词：知青、下乡、回城、推荐、大队、插队
- 雷区：
  - 下乡就是度假
  - 完全没有时代压迫感

## 90 年代下岗逆袭（2026 S 级新晋）

- 一句话定义：女主重生 / 穿越 / 时代亲历者身份在 90 年代国企改革浪潮中下岗，从摆地摊起步逆袭为创业女王
- 女主人设模板：国企老员工觉醒型、纺织 / 化工厂下岗女工型、单亲带娃顽强型、有手艺型（裁缝 / 厨艺 / 美容）
- 男主人设模板：南下做生意的精明商人型、回乡创业的转业军人型、同样下岗但不死心型、暗中扶持型
- 对手盘：原单位势利领导、举报使绊子的同事、嫌贫爱富的婆家 / 娘家、商海老前辈
- 高频场景：
  - 国企发出下岗通知
  - 第一次摆地摊 / 摆烤冷面 / 卖服装
  - 砸锅卖铁开店 / 进货
  - 被旧单位故人羞辱
  - 第一桶金到账
  - 公开亮相成为创业女王
- 标题关键词：下岗、女工、九零、东北、沈阳、女王、地摊、纺织厂
- 标杆案例：《东北 90 之沈阳女王》（红果东北剧场重点 IP）
- 雷区：
  - 90 年代只是壳，剧情完全现代商战化
  - 下岗写成几句话过场，没有具体生存压力
  - 创业过程跳跃，靠旁白发家
  - 遗失国企文化 / 时代特征（厂区、票证残余、工友情）

## 地域文化变体（2026 S 级新晋）

- 一句话定义：以东北 / 南宁 / 川渝 / 西北等具有强地域辨识度的文化场景为底盘，把家庭 / 创业 / 觉醒题材落到具体地域生活感中
- 女主人设模板：地道本地人型、外来嫁入型、回乡创业型、把地域饮食 / 方言 / 习俗当武器型
- 男主人设模板：本地大院 / 老厂子弟型、外来欣赏者型、与女主一同守护地方文化型
- 对手盘：嫌弃地方文化的外来势力、抢夺地方资源的资本、家族中"想脱离地方"的成员
- 高频场景：
  - 一锅老友粉 / 一碗烤冷面 / 一席火锅作为情感引子
  - 方言对白与外地人的反差
  - 老厂区 / 老街 / 大院的具体地理
  - 地方节庆 / 婚俗 / 丧俗作为冲突舞台
- 标题关键词：东北、南宁、平常心、大院、老友、女王、回家、地道
- 标杆案例：《大小姐的平常心》（南宁老友粉 IP，番茄热度 2439 万 + 红果 1363 万）
- 雷区：
  - 地域只贴地名标签，没有方言 / 饮食 / 服化道落地
  - 把地域文化当猎奇看点而非情感共振
  - 对方言使用过度导致非本地读者理解困难
  - 缺少与现代主流生活的连接，沦为纪实纪录片

## 年代/穿越类通用特征

### 时代背景分级

| 时代 | 核心压力 | 常用冲突 |
|------|---------|---------|
| 五六十年代 | 物资极度匮乏、运动 | 分家、饥饿、成分问题 |
| 七十年代 | 末期松动、知青回城 | 高考恢复、回城名额、站队 |
| 八十年代 | 改革开放、个体经济 | 做生意、暴富、城乡冲突 |
| 九十年代 | 下岗潮、南下打工 | 家庭变故、阶层分化 |

### 短剧适配要点

- **优势**：怀旧感 + 生存压力 + 年代滤镜天然有辨识度
- **场景成本**：需要年代服化道，但核心场景（农村大院、部队、学校）有限可控
- **AI漫剧友好度**：高——年代服饰、农村场景、部队大院均有成熟AI绘图素材
- **切片性**：每个生存难题、每次家庭冲突都可独立成切片

### 与其他主类的区分

- 如果核心冲突是"豪门婚恋+身份羞辱"但套了年代壳 → 仍归 `总裁`
- 如果核心冲突是"古代王府/宫廷规则+身份翻盘"→ 归 `古言`
- 如果核心冲突是"年代生存压力+时代规则+穿越/重生金手指"→ 归 `年代/穿越`
- 如果核心冲突是"现代家庭压迫+女性觉醒"只是设在年代 → 归 `女频现实情感`

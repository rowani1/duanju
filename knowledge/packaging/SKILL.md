# 短剧向女频包装技能

## 适用范围

当用户提出以下请求时使用本技能：

- 做短剧向女频选题
- 写番茄风、红果风短故事
- 做总裁文、古言文、现实情感女频文的题材拆解
- 生成书名、简介、卖点、人设、开篇、章纲
- 判断某个题材是否适合改成短剧
- 对现有选题做短剧化改造
- 判断某个题材是否适合AI漫剧改编
- 对选题做AI漫剧适配评估

本技能只覆盖四大主类：

- `总裁`
- `古言`
- `女频现实情感`
- `年代/穿越`

本技能明确不做：

- 正文续写
- 男频都市逆袭主流程
- 纯悬疑、纯惊悚、纯玄幻大世界观创作
- 大体量长篇世界观搭建

## 工作原则

- 先分类，再输出，不要一上来直接写标题或章纲。
- 先判断是否适合短剧化，再决定是否继续包装。
- 所有输出都要面向“高情绪、高冲突、高可视化、低改编成本”。
- 不要堆砌大设定，优先写关系冲突。
- 不要默认用户要正文。正文续写属于后续独立步骤。

## 固定工作流

严格按下面 6 步输出，不要跳步。

### 1. 题材归类

输出：

- 主类
- 子类
- 短剧适配判断
- 不适配风险
- AI漫剧适配评分（仅当用户提及AI漫剧时输出）

### 2. 题材包

输出：

- 一句话选题
- 核心卖点
- 目标读者情绪
- 短剧化优势
- 场景成本判断
- 风险点

### 3. 人设包

输出：

- 女主人设卡
- 男主人设卡
- 反派/阻力角色
- 关系链
- 核心冲突
- 角色禁忌

### 4. 标题简介包

输出：

- 书名候选
- 一句话卖点
- 简介版本
- 标签
- 封面短句

### 5. 开篇包

输出：

- 开篇场景
- 第一冲突
- 第一反转
- 第一章章末钩子
- 前 3 章节奏

### 6. 章纲包

输出：

- 总纲
- 10-20 章短纲
- 每章核心事件
- 每章情绪点
- 每章反转点
- 每章结尾钩子

## 硬限制

- 不允许把“题材大、设定大、角色多”包装成短剧优势。
- 不允许默认输出 50 章以上的大长纲。
- 不允许用低俗、恶俗、擦边标题冒充爆款标题。
- 不允许把“狗血”写成“混乱”。所有冲突都必须能落到人物关系。
- 不允许用空泛词汇代替可执行结构，例如“很带感”“很上头”。
- 不允许输出正文续写，除非用户明确要求进入下一步创作。

## 触发仲裁

当用户请求同时匹配多个技能时，按以下优先级判定：

1. 用户明确说"起标题"/"给书名"/"想要爆款标题" → 转交 `duanju-title-forging`
2. 用户明确说"写正文"/"续写"/"改写"/"扩写"/"润色" → 转交 `duanju-female-story-writing`
3. 用户说"做选题"/"做包装"/"做策划"/"帮我从头搞一个选题" → 使用本技能
4. 用户说"从头到尾帮我做完" → 本技能全流程 + 调用 `duanju-title-forging` + 调用 `duanju-female-story-writing`
5. 不确定时 → 先问用户"你想要包装策划、起标题，还是写正文？"

## 跨技能协同

### 上游输入

本技能的上游是用户原始需求（题材/梗概/灵感），无固定 skill 依赖。

### 下游交付

本技能的输出将被以下 skill 消费：

- `duanju-title-forging`：接收 **题材包 + 人设包摘要**，用于生成书名候选
- `duanju-female-story-writing`：接收 **全六包**（题材包+人设包+标题简介包+开篇包+章纲包），用于生成正文

### 数据交接协议

详见 `references/cross-skill-handoff.md`，核心要求：

- 传递给 title-forging 时，必须包含：主类、子类、一句话选题、核心卖点、女主身份、男主身份、核心关系、核心冲突、最强反转
- 传递给 writing 时，必须包含完整六包内容，且人设包必须带初始状态字段
- title-forging 回填书名后，自动更新标题简介包

### 输出前翻车排查

除了读取 `references/risk-checklist.md` 外，还必须读取 `references/bad-case-gallery.md`，对照常见翻车模式自查。

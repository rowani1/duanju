# 总裁正文写法

## 适合的核心线路

- 离婚后追妻
- 先婚后爱
- 替嫁错嫁
- 假千金反击
- 带娃回归
- 少夫人地域变体（2026 新增）
- 双向治愈型（2026 新增）
- 疯批囚禁 + 高岭之花跌落（2026 新增）

## 最稳开局

- 离婚/复婚现场
- 酒局/会所羞辱
- 女主求人
- 女主被围堵，男主出场

## 正文特点

- 台词要冲
- 男女主对峙要强
- 身份压制感要明显
- 但男主必须逐步破防

## 常用推进

- 女主被逼到绝境
- 男主嘴硬出手相护
- 外人羞辱女主
- 女主身份或能力逐渐反压
- 男主后悔越来越明显

## 爽点排列

- 被压
- 被护
- 被证明
- 被追

## 注意

- 不要全章写甜
- 不要男主一直无脑毒舌
- 不要让女主只能靠男主救

# 总裁专属爽点排列公式

```
被虐得具体 → 第一次被看见 → 被护得有力 → 身份反压 → 男主後悔得真實
```

### 关键爽点展开

| 爽点 | 什么算到位 | 什么算翻车 |
|------|---------|---------|
| 被虐 | 虐在具体细节：存折、羞辱话、等不到的人 | 只说"她很难过"没有场景 |
| 被看见 | 男主第一次注意到她某个细节 | 旁白直接说"他喜欢上她了" |
| 被护 | 男主用权力/行动挡掉伤害（不解释） | 男主深情告白长篇大论 |
| 反压 | 女主用事实/证据/身份碾压对方 | 女主全靠男主撑腰 |
| 后悔 | 男主发现自己错了但已经追不回了 | 男主一求和女主就原谅 |

# 2026 新子类写作要点

## 少夫人地域变体（《少夫人在东北》线）

### 写作核心

- **方言落地**：男主或女主至少使用一种地域口音 / 用词（东北：嗯哪、唠嗑、整事；川渝：要得、巴适；南宁：哈罗）
- **饮食锚点**：每 3-4 章嵌入 1 个具体地方饮食（烤冷面 / 锅包肉 / 老友粉 / 火锅），作为情感引子
- **大院 / 老厂 / 老街地理**：场景固定在具有地域辨识度的物理空间
- **冲突要嫁接到地域文化**：不是"她和婆家撕"，是"她和大院里那帮老姨撕"

### 标志性文风示例

> 大院儿那帮老姨又凑齐了。腊月二十三，小年。
>
> 她端着一盆酸菜走过去。"婶儿，借您家咸盐使使？"
>
> 张婶儿斜着眼："听说你是从南边来的？"
>
> "哈尔滨。"她声音不大，"工大毕业的。"
>
> 屋里的麻将声停了。

### 特别雷区

- 把地域只当背景标签，写成普通都市文换皮
- 方言用得过度，外地读者完全看不懂
- 把地域文化当猎奇看点而非情感共振

## 双向治愈型（《念念有词》线）

### 写作核心

- **女主话密 / 阳光 / 直球**：开篇就建立"她说他听"的反差节奏
- **男主沉默有具体原因**：缄默症 / 童年创伤 / 选择性失语，不要写成单纯高冷
- **治愈通过具体动作**：男主默默写下"她说过的话"、女主第一次听到他说"嗯"——具体物件 / 具体时刻
- **不要急着甜**：前 1/3 是女主单方面"灌注"

### 标志性文风示例

> 他还是不说话。
>
> "你今天值班对吧？"她坐在他旁边，"我给你带了海鲜粥。"
>
> 他点头。
>
> "那你想吃饺子还是面条？我做。"
>
> 他没动。
>
> "好吧，我都做。"
>
> 当晚，她在他枕头底下，看见一本厚厚的笔记。第一页只有一句话：
>
> "她今天来了三次。"

### 特别雷区

- 男主全程毫无回应，沦为植物人设
- 女主的"话痨"变成单方面唠叨，没有信息和情感价值
- 治愈太顺利，没有过程和挫折

## 疯批囚禁 + 高岭之花跌落

### 写作核心

- **男主跌落要"具体跌"**：他在公司请假、在她门口蹲守、在朋友圈发疯
- **囚禁要克制写**：可以是"控制行程""阻止她走"，但不能写违法重口情节（合规红线）
- **女主必须保持清醒**：她不能因男主跌落就立刻心软，必须有"看清"的过程
- **跌落与真相挂钩**：男主疯批不是无缘由，背后藏着"我以为你不爱我了""我以为是你害的"等可被揭开的结

### 特别雷区

- 疯批写成无脑施暴，违反女频"先虐后爽 + 男主低位"的爽感逻辑
- 囚禁过实，触碰平台合规红线
- 男主始终高位无代价，让女主像受害者而非掌控者

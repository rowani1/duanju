# 系列化写作与养 IP 指导

> 适用：当项目被标记为"系列第 N 部"时读取。
> 目的：对齐 2025-2026 年"从卖剧转向养 IP"趋势，支持跨部角色成长、伏笔延展、世界观累积。

## 核心立场转变

### 从"单部爆款"到"养 IP"

| 维度 | 单部爆款模式 | 养 IP 模式 |
|------|------------|-----------|
| 单部定位 | 自足闭环 | 整体章节 |
| 角色深度 | 满足本部需求即可 | 需要跨部成长空间 |
| 伏笔处理 | 本部全部收束 | 部分伏笔留给下部 |
| 结局处理 | 大团圆/强收束 | 收束主线 + 留开放空间 |
| 封面策略 | 独立设计 | 形成视觉系列 |
| 读者期待 | 看完一部再说 | 主动预告下部 |

## 系列化三种主要形态

### 形态 1：主角续集型（同一 CP，多段故事）

- 例：总裁文第一部讲结婚前的追妻，第二部讲婚后带娃创业
- 难点：同一 CP 如何保持新鲜感
- 关键：第一部必须在 CP 稳定后留下"新外部压力"钩子（新反派/新事业危机）

### 形态 2：群像拓展型（同世界观，不同 CP）

- 例：第一部是大姐的故事，第二部切到二姐，第三部切到妹妹
- 难点：每部换主角但共享家族/世界观
- 关键：核心家族成员的底层关系/秘密必须逐部揭开一层

### 形态 3：时间延续型（同主角，多年龄段）

- 例：第一部女主 18 岁，第二部 25 岁，第三部 30 岁
- 难点：人物成长弧长、风格可能变化
- 关键：每部有独立成长主题（成家/立业/育儿/寻亲），但性格底层稳定

## 跨部伏笔管理

### 伏笔分级

| 级别 | 定义 | 处理方式 |
|------|------|---------|
| L1 本部伏笔 | 本部内埋本部内收 | 按单部规则处理 |
| L2 跨部伏笔 | 本部埋下部收 | 必须在本部结尾明确"未解" |
| L3 系列级伏笔 | 贯穿 3 部以上 | 每部解一层，总谜底留给终章 |

### L2 跨部伏笔的三条铁律

1. **必须有可识别的提示点**：不能纯隐藏，要让读者感受到"这里有东西"（但本部不揭）。例：第 1 部结尾，男主收到一封未署名的信，女主注意到他表情变化，但没追问。
2. **不能超过 3 个**：跨部伏笔太多读者记不住，且会稀释主线。
3. **必须和下部主冲突挂钩**：不能是装饰性悬念，要是下部剧情的直接燃料。

### 跨部伏笔清单模板

```markdown
## 第 N 部留给第 N+1 部的伏笔

| 编号 | 伏笔内容 | 提示点位置 | 预计揭开章节 | 优先级 |
|------|---------|-----------|------------|--------|
| F01 | 男主家族的真实身份 | 第 28 集结尾匿名信 | 第 N+1 部第 5 集 | 高 |
| F02 | 女主妹妹的失踪真相 | 第 35 集童年回忆 | 第 N+1 部第 15 集 | 中 |
| F03 | 反派隐藏的靠山 | 第 42 集反派电话被打断 | 第 N+1 部第 20 集 | 中 |
```

## 角色成长弧跨部追踪

### 全系列成长弧模板（3-5 部）

```
第 1 部：起点（觉醒 / 第一次反抗 / 建立独立人格）
第 2 部：承转（巩固 / 遇到更大挑战 / 能力升级）
第 3 部：转（重大打击 / 动摇 / 反省）
第 4 部：合转（重新站起来 / 整合经验 / 更成熟的她）
第 5 部：终章（俯瞰全局 / 放下 / 传承）
```

### 每部应保持的底层一致性

即便经历再大变化，以下三条是"她还是她"的锚点：

1. **核心价值观** —— 她在乎什么永远不变（例：家人/真相/尊严）
2. **口癖/小动作** —— 生气时会做同样的动作、高兴时会说同一句话
3. **某个最怕失去的东西** —— 这条贯穿所有部，到哪部都是她的死穴

### 变化的部分

以下是每部都可以/应该改变的：

- 能力范围（更强）
- 人际关系网（更广）
- 心态成熟度（更稳）
- 处理冲突的方式（更有策略）

## 系列化的风险清单

### 🔴 致命风险

- **人设断裂**：第 2 部女主突然性格大变，读者认不出来
- **伏笔悬空**：第 1 部埋的大坑第 2 部没动静，读者失望
- **世界观矛盾**：第 1 部说女主无亲无故，第 2 部突然冒出堂姐
- **主线稀释**：为了养 IP 故意不收束，导致第 1 部观感糟糕

### 🟡 可修风险

- **情感烈度重复**：每部都用"全家背叛"做开篇压力，审美疲劳
- **反派套路化**：每部反派都是"嫉妒型前女友"
- **甜戏位置固定**：每部都在 80% 位置才有第一次亲吻，观众等得没耐心

## 每部内部的系列化节奏调整

### 相对独立作品的差异

| 环节 | 独立作品 | 系列作品 |
|------|---------|---------|
| 开篇 | 直接切入冲突 | 可用 1-2 章带上部摘要（新读者友好） |
| 中段 | 全力推进本部主线 | 在推进主线时偶尔释放跨部伏笔提示点 |
| 结尾 | 大团圆/完全收束 | 收束本部主线，但留 1-3 个可见伏笔 |
| 彩蛋 | 番外 | 直接下部预告（新角色出场/新场景暗示） |

## 数据交接协议

当项目标记为"系列第 N 部"时，writing 技能从 packaging 必须接收：

- 系列总章程（各部在整体中的定位）
- 上部遗留伏笔清单（L2/L3 级）
- 主角跨部成长状态（当前处于整体弧的哪个位置）
- 核心价值观/口癖/死穴三件套（稳定性锚点）

详细字段见 `packaging/references/cross-skill-handoff.md` v1.1。

## 实操检查清单

系列作品每部完稿前，逐项检查：

- [ ] 本部主线是否收束？（必须闭环，不允许"全部问题留给下部"）
- [ ] 跨部伏笔是否清晰且不超过 3 个？
- [ ] 女主核心三件套（价值观/口癖/死穴）是否与上部一致？
- [ ] 是否有 1-3 章是为"下部做准备"的铺垫？（可以有，但不能超过总量的 15%）
- [ ] 本部结尾有没有"新外部压力"信号？（支撑下部开篇）
- [ ] 封面/标题是否与系列整体形成视觉呼应？

## 参考案例（2025 番茄/红果养 IP 趋势）

- 番茄系列化爆款：部分真千金/豪门系列做到 3-5 部联动
- 红果剧场：头部 IP 开始拍续集（《家里家外》《东北爱情故事》均有第二部规划）
- 漫剧 IP：天然长篇特性，更适合养 IP 模式（单部 50-80 集仍属中篇）

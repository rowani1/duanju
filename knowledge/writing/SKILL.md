# 短剧向女频正文创作技能

## 适用范围

当用户提出以下请求时使用本技能：

- 写短剧向女频正文
- 根据题材包、人设包、章纲写第一章或后续章节
- 续写已存在的短篇短故事
- 改写、扩写、润色、重写节奏
- 把一段普通女频文改成更像番茄+红果风
- 写AI漫剧适配脚本/正文（画面锚点写作法）

本技能只覆盖四大主类：

- `总裁`
- `古言`
- `女频现实情感`
- `年代/穿越`

本技能默认服务：

- 总篇幅：`1.5万-3万字`
- 单章长度：`2000-4000字`

本技能明确不做：

- 男频都市逆袭主流程
- 悬疑、惊悚、玄幻大世界观正文
- 超长连载模式
- 只有设定没有人物关系的创作

## 风格总方向

- 底层阅读感：`番茄可读性`
- 节奏骨架：`红果短剧感`

意味着：

- 语言清楚、顺滑、口语化
- 节奏要快，冲突要密
- 章节切片感强
- 每章都必须有推进和钩子

## 输入优先级

- 本章章末钩子

## 固定工作流

严格按以下 5 步工作：

### 1. 判断任务模式

先判断属于哪一种：

- 新写正文
- 按章续写
- 改写
- 扩写
- 润色
- 重写节奏

### 2. 锁定本章目标

每次写正文前都要明确：

- 本章核心事件
- 本章情绪主轴
- 本章反转
- 本章结尾钩子

### 3. 决定推进方式

本章正文必须至少包含以下 3 项中的 2 项以上：

- 对峙
- 行动
- 真相推进
- 关系变化

### 4. 生成正文

写法要求：

- 开头尽快进入事件
- 多用对白推进
- 少讲大道理
- 少做空心理
- 每 500-1000 字给一次小波动

### 5. 输出前自检

重点检查：

- 有没有灌水
- 有没有假冲突
- 有没有人物失真
- 有没有章末钩子

## 硬限制

- 不允许慢热开篇。
- 不允许一章只讲背景，不推进。
- 不允许只写情绪，不写事件。
- 不允许只写甜，不写压。
- 不允许反转只是“他说了个秘密”，却不改变关系。
- 不允许把文风写成散文化抒情。

## 默认输出要求

正文默认直接输出正文内容，不加解释。

如果用户要求的是改写、扩写、润色、重写节奏，只输出处理后的正文，不要附带分析，除非用户明确要求说明。

## 触发仲裁

当用户请求同时匹配多个技能时，按以下优先级判定：

1. 用户明确说"起标题"/"给书名" → 转交 `duanju-title-forging`
2. 用户明确说"做选题"/"做包装"/"做策划" → 转交 `duanju-female-novel-packaging`
3. 用户说"写正文"/"续写"/"改写"/"扩写"/"润色"/"重写节奏" → 使用本技能
4. 不确定时 → 先问用户

## 角色状态继承协议

续写时，必须在动笔前完成角色状态锁定：

1. 读取 `references/character-state-tracker.md` 中的模板
2. 从上一章正文中提取每个角色的当前状态
3. 填写角色状态快照，包括：当前情绪、当前关系位置、已知/未知信息、最后一个动作
4. 检查伏笔池，确认未揭示伏笔的管理状态
5. 本章写作过程中，角色行为不得违反状态快照中的约束

## 字数预算声明

每次生成正文前，必须先声明本章目标字数：

- 默认范围：2000-4000 字
- 声明格式："本章目标字数：约 X 字（±10%）"
- 实际输出字数与声明偏差不得超过 ±15%
- 如果用户指定了字数，以用户要求为准

## 章节连续性检查

续写或新章节开始时，必须完成以下检查：

1. **回读上一章最后 500 字**，确认场景、情绪、未完成事件
2. **检查章首衔接**：本章前 2-3 句必须"接住"上一章的最后场景或情绪
3. **检查时空连续性**：上一章结束的时间和地点 → 本章开始的时间和地点，如有跳跃必须交代
4. **检查角色情绪延续**：不能无缘由地突变
5. **检查信息边界**：角色不能"突然知道"不应该知道的信息

## AI 病症自检

正文输出前，对照 `references/ai-pitfall-catalog.md` 逐项检查：

- 角色是否突然 OOC？
- 冲突是否无故蒸发？
- 对白是否变成说教？
- 情节是否原地转圈？
- 章尾钩子是否是"假钩子"？
- 是否出现全员温柔化？

# 女频现实情感标题模板

## 高优先级子类

- 婚姻反击
- 全家后悔
- 原生家庭反杀
- 姐妹撕裂
- 无 CP 大女主成长（2026 新增）
- 流产流（2026 新增，注意合规）

## 核心身份词

- 前夫
- 全家
- 婆家
- 妹妹
- 姐姐
- 亲哥
- 妈妈
- 大女主（2026 新增）
- 我自己（2026 无 CP 线）

## 核心关系词

- 离婚后
- 断亲
- 偏心
- 抛弃
- 后悔
- 反击
- 不原谅
- 失去（2026 流产流，注意克制使用）
- 不嫁了 / 不爱了（2026 无 CP 线）

## 核心反转词

- 后悔了
- 不再原谅
- 高攀不起
- 跪求
- 我杀回来了
- 我不要这个家了
- 不为他人活了（2026 无 CP 线）
- 是她（2026 流产流，揭穿型）

## 模板

- 《离婚后，前夫一家都后悔了》
- 《全家偏心妹妹后，我断亲了》
- 《被婆家逼到绝境后，我杀回来了》
- 《姐姐被全家吸血后，不忍了》
- 《被抢走人生后，我翻盘了》
- 《前夫后悔时，我已经不是从前的我》
- 《离婚后，我才发现自己不需要老公》（2026 无 CP）
- 《这一次，我不为任何人活》（2026 无 CP 宣言型）
- 《不嫁，全家都急了》（2026 无 CP + 全家后悔联动）
- 《失去孩子那天，我看清了所有人》（2026 流产流，克制型）
- 《孩子不是意外，是她》（2026 流产流，揭穿型）

## 风格要求

- 情绪要近身
- 现实议题要可感
- 不要写成鸡汤
- 2026 新方向：无 CP 大女主成长是首选差异化路线，流产流题材必须克制并有反击

## 不推荐写法

- 纯温柔成长系标题
- 空喊女性力量
- 没有具体关系压迫
- 流产流标题过于猎奇 / 过度消费苦难（不合规）
- 名义无 CP 实际大量恋爱信号

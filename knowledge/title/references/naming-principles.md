# 爆款命名总原则

## 总结来源

本技能基于两类样本归纳：

- 番茄短故事目录型标题
- 红果短剧热榜与年度榜剧名

目标不是生成“文学名”，而是生成“高转化标题”。

## 核心原则

### 1. 先交代冲突，再交代美感

- 标题第一职责是让读者一眼明白这是什么故事
- 如果只能保一个，优先保冲突，不保文艺感

### 2. 标题必须有一个强信息钉子

至少有一项特别强：

- 身份
- 关系
- 反转
- 情绪宣言

### 3. 短剧向标题优先长于短

- 纯四字、六字标题通常不够交代信息
- 短剧向女频更适合 `10-18字`
- 必要时可以用逗号结构增强信息密度

### 4. 关系比世界观更重要

- 标题里尽量不要写大设定
- 优先写“谁和谁”以及“发生了什么关系变化”

### 5. 反转词是点开率核心

高频有效反转：

- 后悔了
- 不再原谅
- 驾到
- 成了
- 找上门
- 宠上天
- 高攀不起
- 疯了
- 超爱

## 番茄短故事与红果短剧的差别

### 番茄短故事

- 可接受更灵活、更实验的标题
- 容易出现句子型、目录型标题
- 有时更像单篇故事梗概

### 红果短剧

- 更强调身份、关系、情绪
- 更像投流标题
- 一眼必须看懂强冲突

## 本技能的取向

本技能以 `红果命名强度` 为主，以 `番茄可读性` 为辅。

一句话原则：

- 先让人点，再让人觉得顺口

# 标题评分卡

每个标题候选按以下 5 个维度打分，每项 1-5 分：

| 维度 | 1 分 | 3 分 | 5 分 |
|------|------|------|------|
| 冲突感 | 看不出故事有冲突 | 有冲突但不够尖锐 | 一眼就知道谁和谁怎么了 |
| 身份感 | 看不出人物身份 | 有身份但太泛泛（如"女人"） | 身份词精准（总裁/王爷/前夫） |
| 关系感 | 看不出关系 | 有关系但不清晰 | 关系一目了然（替嫁/离婚/追妻） |
| 反转感 | 没有期待和悬念 | 有转折但不意外 | 读完就想点进去看 |
| 顺口度 | 拗口/读不通 | 通顺但平淡 | 读起来顺且有记忆点 |

## 评分规则

- **22-25 分**：第一梯队优选
- **18-21 分**：第一梯队可用
- **14-17 分**：第二梯队
- **低于 14 分**：淘汰

## 使用方法

1. 生成 20 个标题后，逐一打分
2. 低于 14 分的直接淘汰
3. 14-17 分的放入第二梯队
4. 18 分以上的放入第一梯队
5. 第一梯队中选出推荐书名

# 番茄 vs 红果平台偏好差异表

| 维度 | 番茄短故事 | 红果短剧 |
|------|----------|---------|
| 标题长度 | 8-20 字弹性较大 | 10-18 字为主流 |
| 信息密度 | 可以偏低，趣味优先 | 必须高，一眼看懂冲突 |
| 文艺度 | 允许少量文艺/趣味标题 | 几乎不允许，直给优先 |
| 逗号结构 | 常见，有时两个逗号 | 最多一个逗号 |
| 身份词要求 | 不强制但推荐 | 几乎强制 |
| 反转词要求 | 可选 | 几乎强制 |
| 创新空间 | 较大（谐音、反套路） | 较小（套路化但高效） |
| 代表爆款 | 《念念有词》《好一个乖乖女》 | 《离婚后，顾总他疯了》《冲喜王妃一睁眼，王爷活了》 |
| 用户画像 | 偏年轻、猎奇、碎片阅读 | 偏下沉、情绪共鸣、连续追剧 |

## 如何选择风格

- 用户指定"番茄/短故事" → 番茄风
- 用户指定"红果/短剧" → 红果风
- 用户未指定 → 通用风（第一梯队红果标准，第二梯队可番茄创新）

### 通用风混合策略（2026 推荐）

第一梯队按红果标准：

- 必须含身份词
- 必须含关系词或地域词
- 必须含反转词
- 字数 10-18 字

第二梯队尝试番茄创新：

- 可用反差人设词（少夫人 / 太奶奶 / 财迷美人 / 缄默症）
- 可用古风句式（此生若得 / 死的第三年 / 上上签）
- 可用地域 + 饮食锚点（《大小姐的{地方饮食}》）

## 2026 系列化 IP 命名建议

> 红果 2025-2026 系列化爆款已成主流，命名时建议预留延展空间。

- 主标题保持简洁，便于挂副标题：《夫人她专治不服 N 之 xx》《十八岁太奶奶驾到 N》《云渺 N》
- 系列号位置：标题尾部（"3"）或副标题前置（"3 之"）
- 副标题用具体冲突 / 角色 / 场景：将门捉婿 / 重整家族荣耀

# AI漫剧标题适配指南

> 当用户明确要求为AI漫剧起标题时，在正常命名基础上额外考虑以下因素。

## AI漫剧标题 vs 传统短剧标题的差异

| 维度 | 传统短剧标题 | AI漫剧标题 |
|------|------------|-----------|
| 投流场景 | 短视频信息流（动态画面+标题叠加） | 静态封面图+标题（竖版漫画封面） |
| 阅读时间 | 0.5-1 秒扫过 | 1-2 秒停留（图文结合阅读） |
| 字数偏好 | 10-18 字 | 8-16 字（封面排版需留空间给画面） |
| 视觉配合 | 标题独立承担信息 | 标题+封面图共同承担信息 |

## AI漫剧标题原则

### 1. 更短更炸

AI漫剧封面需要大面积给画面，标题空间更小。优先 **8-14 字**。

### 2. 画面感更强

标题本身最好能让人"看到画面"：

- ✅ 《凤冠新娘跪在雪地里》——有画面
- ❌ 《命运的抉择》——没画面

### 3. 配合封面截图

标题应该和"名场面截图"形成互补：

- 封面图是"她穿着婚纱站在雨里"→ 标题补充冲突："婚礼当天，他牵着别人来了"
- 封面图是"他跪在她面前"→ 标题补充反转："追妻满三年，她头也不回"

### 4. 竖版排版友好

- 避免超长标题被折行截断
- 逗号结构仍然有效，但前后两半各不超过 8 字
- 如果标题超过 14 字，检查竖版封面排版是否可读

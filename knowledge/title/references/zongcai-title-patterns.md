# 总裁类标题模板

## 高优先级子类

- 追妻火葬场
- 先婚后爱
- 离婚逆袭
- 替嫁错嫁
- 真假千金
- 带娃回归
- 少夫人地域变体（2026 新增）
- 双向治愈型（2026 新增）
- 疯批囚禁 + 高岭之花跌落（2026 新增）

## 核心身份词

- 总裁
- 顾总
- 霍爷
- 贺少
- 夫人
- 甜妻
- 前夫
- 白月光
- 千金
- 萌宝
- 少夫人（2026 新增）

## 核心关系词

- 离婚后
- 复婚
- 追妻
- 闪婚
- 替嫁
- 带娃
- 回国
- 找上门
- 宠
- 在东北 / 在川渝 / 在南宁（2026 地域型）

## 核心反转词

- 疯了
- 后悔了
- 超爱
- 高攀不起
- 宠上天
- 不装了
- 失控了
- 不语 / 念念有词（2026 治愈型）
- 沦陷了 / 跌落神坛（2026 疯批型）

## 模板

- 《离婚后，{身份词}{反转词}》
- 《{替嫁/错嫁}后，我成了{身份词}{情感位}》
- 《带着{孩子/马甲}回归，{身份词}{反转词}》
- 《被赶出豪门后，{高位人物}都在等我回头》
- 《我抢了{继妹/妹妹}的{白月光/联姻对象}》
- 《{身份词}夫人今天也不肯复婚》
- 《闪婚后，{身份词}夜夜护我》
- 《少夫人在{地域}》（2026 地域变体爆款模板，参考《少夫人在东北》）
- 《{地域}少夫人，今天也不肯回去》
- 《嫁给缄默症总裁后，他写了一本《她说过的话》》（2026 双向治愈）
- 《追妻三年，{总裁/顾总}他终于跌落神坛》（2026 疯批跌落）

## 风格要求

- 直给
- 关系强
- 身份显性
- 不要太文艺
- 2026 新方向：身份 + 地域 / 治愈 / 疯批跌落，三者均为差异化突破口

## 不推荐写法

- 纯四字甜宠名
- 纯英文感或都市轻奢空词
- 只有”爱与痛”没有关系主体
- 地域只贴地名，没有具体地域文化锚点

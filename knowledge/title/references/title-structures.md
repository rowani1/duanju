# 标题结构总表

## 1. 身份反差型

公式：

- `{极端身份} + {反差动作/命运}`
- `{年龄/身份} + {进入高位局}`

适合：

- 古言
- 现实情感
- 部分总裁
- 年代/穿越

例型：

- 十八岁太奶奶驾到，重整家族荣耀
- 郡主十岁，我把纨绔爹养成皇帝啦

## 2. 强关系型

公式：

- `{人物A} + {如何对待人物B}`
- `{关系A} + {关系B} + {站队反差}`

适合：

- 总裁
- 古言
- 年代/穿越

例型：

- 王府继兄宠我如宝，亲哥却后悔了
- 甜妻似火，霍爷他超爱

## 3. 强冲突型

公式：

- `{事件} + {情绪选择}`
- `{被怎样对待} + {我如何反击}`

适合：

- 现实情感
- 总裁
- 年代/穿越

例型：

- 重生后，我选择不再原谅
- 出狱当天，世间再无我

## 4. 身份词 + 反转词型

公式：

- `{身份词} + {处境} + {反转}`

适合：

- 全部四类

例型：

- 好孕甜妻被钻石老公宠上天
- 替嫁后，病弱王爷他不装了

## 5. 逗号长标题型

公式：

- `{前置设定}，{后置反转}`

适合：

- 全部四类

说明：

- 当前短剧向女频最稳结构之一
- 可以在不加副标题的情况下提高信息密度

## 6. 情绪宣言型

公式：

- `{主角宣言/立场}`

适合：

- 现实情感
- 重生反击
- 年代/穿越

例型：

- 重生后，我选择不再原谅

## 7. 反套路/谐音/悬念型

公式：

- `{常规套路的反向操作}`
- `{谐音双关/语言游戏}`
- `{悬念设问/反常识}`

适合：

- 番茄短故事优先
- 四大主类均可尝试（偏第二梯队创新位）

说明：

- 这类标题不靠身份词和反转词取胜，靠的是"意外感"和"趣味感"
- 在番茄短故事平台上转化率不错，但红果端需谨慎使用
- 风险：如果反套路不到位，容易变成"看不懂"
- 建议：作为第二梯队候选，不做第一梯队主力

例型：

- 好一个乖乖女（反讽型）
- 念念有词（谐音双关型）
- 全家穿越六零年代，就我是原装的（反常识悬念型）
- 穿书后我成了男主他妈（反套路身份型）

## 使用规则

- 每次至少用两种结构并行生成
- 如果题材靠关系驱动，优先 `强关系型`
- 如果题材靠身份落差驱动，优先 `身份反差型`
- 如果题材靠反击爽点驱动，优先 `强冲突型`
- 如果目标平台偏番茄风，可在第二梯队使用 `反套路/谐音/悬念型`
- `反套路型` 不能做第一梯队主力（除非用户明确要求番茄风创新标题）

- 好孕甜妻被钻石老公宠上天

- 穿书女配带着空间，躺赢了
- 知青嫁到穷山沟，转头成了万元户

## 逗号长标题型

- 离婚后，顾总他疯了
- 带着双胞胎回国，前夫跪了
- 替嫁那天，冷面王爷他不装了
- 嫁入侯府第三天，我把规矩翻了
- 被赶出家门后，我成了全城首富
- 穿越第一天，我就被逼分家了
- 随军后才发现，残疾丈夫是大佬

## 情绪宣言型

- 重生后，我选择不再原谅
- 这一次，我不做谁的替身
- 全家欠我的，我自己讨回来
- 从今天起，我只为自己活
- 穿回六零，这辈子我只疼自己人

## 反套路/谐音/悬念型

- 好一个乖乖女（反讽：人设反差，乖乖女其实不乖）
- 念念有词（谐音双关：人名+能力暗示）
- 全家穿越六零年代，就我是原装的（反常识：打破穿越套路）
- 穿书后我成了男主他妈（反套路身份：穿书但身份出乎意料）
- 恶毒女配每天都在保命（反派视角+求生悬念）
- 全侯府都在等我和离，我偏不（反套路宣言：不按套路走）

# 结构混搭规则

## 允许的混搭

| 混搭组合 | 效果 | 示例 |
|---------|------|------|
| 身份反差 + 逗号长标题 | 信息密度最高 | 《十八岁太奶奶驾到，重整家族荣耀》 |
| 强关系 + 反转词 | 既有关系又有悬念 | 《王府继兄宠我如宝，亲哥却后悔了》 |
| 强冲突 + 情绪宣言 | 既有事件又有态度 | 《被赶出家门后，我再也不回头》 |
| 反套路 + 逗号长标题 | 趣味+信息密度（番茄风） | 《穿书后我成了男主他妈，全家靠我养》 |

## 不允许的混搭

| 禁止组合 | 原因 |
|---------|------|
| 身份反差 + 情绪宣言 | 身份信息太多+宣言太长 → 标题超长 |
| 强关系 + 强冲突 | 两者都需要句子承载 → 信息过载 |
| 反套路 + 强关系 | 反套路靠意外感，强关系靠正面信息，互相冲突 |
| 三种以上结构混搭 | 必定超过 22 字且无法读懂 |

## 混搭判断流程

1. 先确定主结构（1 种）
2. 如果标题评分低于 18 分，尝试叠加 1 种辅助结构
3. 叠加后如果超过 22 字 → 砍掉辅助结构
4. 永远不超过 2 种结构
